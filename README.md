# AI Workflow Companion

Act as a Senior Full-Stack Engineer and UX Designer. Help me build a modern, responsive web application designed to help professionals automate workplace tasks using AI. 

### Core Features to Implement

1. **Smart Email Generator**

   - Generate context-based professional emails based on brief user inputs.

   - Include options for tone selection (Formal, Informal, Persuasive, Direct).

   - Adapt tone and structure based on audience type (Client, Manager, Internal Team).

2. **Meeting Notes Summarizer**

   - Transform lengthy, unstructured meeting transcripts or notes into concise executive summaries.

   - Automatically extract key discussion points, core decisions, and an actionable task list.

   - Explicitly highlight deadlines, assignees, and responsibilities.

3. **AI Research Assistant**

   - Summarize articles, reports, or complex topics into digestible insights.

   - Generate key takeaways, strategic recommendations, and simplified explanations for fast decision-making.

### Application Layout & UX Requirements

- **Dashboard Layout:** Clean, professional visual hierarchy designed for productivity.

- **Sidebar Navigation:** Easy access to switch between the three tools (Email, Meetings, Research), Settings, and History.

- **Input & Output Interface:** Clear dual-pane or stacked arrangement with distinct "Input" forms/text areas and formatted "Output" display areas featuring a 1-click "Copy to Clipboard" button.

- **Responsible AI Disclaimer:** A persistent, non-intrusive footer or modal banner emphasizing that AI outputs should be reviewed prior to professional sending/publishing.

### Deliverables

Provide a step-by-step blueprint to build this application, including:

1. **Recommended Tech Stack:** Frontend framework, UI component library, state management, backend service, and target AI API/LLM choices.

2. **System Architecture & Data Flow:** High-level overview of how the frontend, backend server/edge functions, and AI APIs will communicate safely.

3. **UI/UX Wireframe Code:** Clean, production-ready frontend code (e.g., React/Tailwind CSS or HTML/CSS) for the main layout shell and dashboard navigation.

4. **Prompt Engineering Templates:** Ready-to-use system prompts for each of the three core AI tools to ensure high-quality outputs.
